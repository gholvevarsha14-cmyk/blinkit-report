
# 🛒 Blinkit Sales & Performance Analytics Dashboard

## 📌 Project Overview
This project presents an end-to-end data analysis and interactive Power BI report for **Blinkit** (India's Last-Minute Delivery App). The dashboard analyzes key business metrics—including total sales, average order values, customer ratings, and product performance—to identify growth opportunities, optimize inventory distribution, and evaluate outlet efficiency.



## 🔑 Key Performance Indicators (KPIs)
* **Total Sales ($):** Overall revenue generated across all outlets.
* **Average Sales:** Mean transaction value per item sold.
* **Number of Items Sold:** Total volume of inventory moved.
* **Average Customer Rating:** Mean user feedback score across product categories.



## 📊 Dashboard Features & Insights
1. **Sales Breakdown by Fat Content & Item Type:** Segmented view showing how low-fat vs. regular products perform across categories.
2. **Outlet Size & Location Analysis:** Evaluates revenue generated by tier level (Tier 1, 2, 3 cities) and outlet footprint (Small, Medium, Large).
3. **Outlet Establishment & Growth:** Historical performance trends relative to outlet age and establishment year.
4. **Item Category Performance:** Deep-dive metrics on fast-moving consumer goods (FMCG), dairy, produce, and packaged items.



## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Data modeling, DAX measure creation, visualization layout, and custom UI design.
* **Power Query:** Data extraction, transformation, and cleaning (ETL pipeline).
* **Data Source:** Blinkit transactional and outlet dataset.
